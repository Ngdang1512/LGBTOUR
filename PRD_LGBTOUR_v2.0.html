🎯 LGBTOUR: Hệ Thống Thuyết Minh Xe Buýt 2 Tầng Tại Quận 1

Giải pháp thuyết minh du lịch tự động cho các tuyến xe buýt 2 tầng tham quan Quận 1 (Hà Nội). Khi xe di chuyển vào gần các địa danh lịch sử, văn hóa như Nhà Thờ Lớn, Bưu Điện, Dinh Độc Lập, hệ thống tự động phát âm thanh thuyết minh tiếng Việt/Anh/Hàn giúp du khách hiểu rõ hơn về từng địa điểm.

💻 C# ASP.NET Core 8 📱 Mobile MAUI / Flutter 🗄️ SQL Server 2022 🤖 Azure AI TTS 📊 LeafletJS & ChartJS 🔐 JWT Authentication

Phạm Vi & Mô Tả Dự Án

LGBTOUR - Hệ Thống Thuyết Minh Du Lịch Tự Động Trên Xe Buýt 2 Tầng là giải pháp toàn diện để quản lý và phát hành thông tin du lịch cho các tuyến xe bưu dK tham quan quanh Quận 1 (Hà Nội). Hệ thống tự động phát âm thanh thuyết minh tiếng Việt, tiếng Anh, tiếng Hàn khi xe di chuyển vào vùng các địa danh nổi tiếng.

Các Địa Danh Chính Quận 1 (District 1):

  • 🏛️ Nhà Thờ Lớn (Thánh Josephine)
  • 📮 Bưu Điện Thành Phố (Post Office)
  • 🏛️ Tòa Nhà Patriot (Legend Plaza)
  • 🌊 Bến Nghè - Bờ Sông Sài Gòn
  • 🏰 Dinh Độc Lập (Independence Palace)
  • 🎭 Nhà Hát Thành Phố
  • 👟 Thao Đức Sports Center
  • 🌳 Tao Đức Park

LGBTOUR cung cấp:

  • ✅ Quản trị Địa Danh (POI) - CRUD các điểm tham quan Quận 1 với GPS, bán kính kích hoạt
  • ✅ Quản lý Âm Thanh Đa Ngôn Ngữ - Thuyết minh VI/EN/KO, AI TTS, convert text to speech
  • ✅ Kế Hoạch Tuyến Xe Buýt - Sắp xếp các POI theo lộ trình xe từ Dinh Độc Lập → Bưu Điện → Nhà Thờ Lớn
  • ✅ Phát Âm Thanh Tự Động - Khi xe buýt vào gần địa danh, phát thuyết minh vị trí, lịch sử, kiến trúc
  • ✅ Dashboard Xe Buýt - Theo dõi vị trí xe realtime, số hành khách, lượt nghe từng địa danh
  • ✅ Heatmap Analytics - Phân tích địa danh nào được du khách quan tâm nhất, thời gian lưu lại
  • ✅ CMS Web Quản Lý - CRUD Địa Danh, Upload Âm Thanh, Sắp Xếp Tuyến Xe, Quản Lý Admin

Thiết Kế Cơ Sở Dữ Liệu (Entity Relationship Diagram)

Cấu trúc CSDL chuẩn hóa 3NF (Third Normal Form) trên SQL Server 2022. Hỗ trợ Soft Delete, Audit Logs, Full-Text Search, và Transaction Consistency với ACID properties.

erDiagram POI { int Id PK "Primary Key" string Name "Tên điểm dừng" string Description "Mô tả chi tiết" double Lat "Vĩ độ" double Lng "Kinh độ" string Image "Link ảnh đại diện" int Priority "Thứ tự ưu tiên" bool IsStopStation "Điểm dừng?" int Radius "Bán kính geofence (m)" } Narration { int Id PK "Primary Key" int POI_Id FK "Reference to POI.Id" string LanguageCode "Code: vi, en, ko, zh, ja, es, fr" string TranslatedName "Tên dịch" string TranslatedDescription "Mô tả dịch" string ContentText "Nội dung text cho TTS" string AudioUrl "Đường dẫn file MP3" int DurationSeconds "Thời lượng (giây)" string VoiceType "Loại giọng đọc" } TOUR { int Id PK "Primary Key" string Name "Tên tour du lịch" string Description "Mô tả chuyến đi" int EstimatedTimeMinutes "Thời gian ước tính (phút)" decimal TicketPrice "Giá vé du lịch" double TotalDistanceKm "Tổng khoảng cách (km)" } TourPOI { int Id PK "Primary Key" int TourId FK "Reference to Tour.Id" int POIId FK "Reference to POI.Id" int DisplayOrder "Thứ tự lộ trình (1, 2, 3...)" } UserLog { long Id PK "Primary Key" string UserId "Device ID hoặc User ID" int POIId FK "Reference to POI.Id" double Lat "Vĩ độ khi bắt sự kiện" double Lng "Kinh độ khi bắt sự kiện" string EventType "Loại sự kiện" long DurationSeconds "Thời lượng nghe audio" datetime CreatedAt "Timestamp sự kiện" } POI ||--o{ Narration : "Có bản thuyết minh (1-N)" POI ||--o{ UserLog : "Ghi nhận lượt nghe (1-N)" POI ||--o{ TourPOI : "Nằm trong tour (N-N)" TOUR ||--o{ TourPOI : "Bao gồm POI (1-N)"

🗂️ Tổng cộng 5 bảng chính: POI, Narration, Tour, TourPOI, UserLog

✓ Khóa & Quan Hệ:
• POI & Narration (1-N): Mỗi POI có nhiều bản thuyết minh đa ngôn ngữ
• Tour & TourPOI (1-N): Mỗi Tour bao gồm nhiều POI với DisplayOrder xác định thứ tự
• POI & UserLog (1-N): Mỗi POI ghi lại hoạt động của khách (Lat/Lng/DurationSeconds/EventType)
• Tọa độ dùng double (Lat/Lng) để tính Haversine distance cho geofencing
